# Eros: Chocolate Brand Landing Page

A cinematic landing page for **Eros**, a fictional luxury chocolate brand. This is a concept design and front-end project; the brand, products and customer quotes on the page are invented for the demo.

![Eros hero](assets/hero-poster.jpg)

## Highlights

- Full-screen hero video with auto-cycling captions and a poster fallback
- Respects `prefers-reduced-motion`: animations and video autoplay are reduced for users who ask for it
- Product collection, step-by-step production story, interactive "hold to melt" section, testimonials and FAQ
- Written in Turkish
- No frameworks or build step: plain HTML, CSS and vanilla JavaScript

## Tech stack

| Area | Tools |
| --- | --- |
| Markup and styles | HTML5, CSS (custom properties) |
| Interaction | Vanilla JavaScript |
| Media | Optimized MP4 hero video and JPEG imagery |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
